# 🚀 area-cli: 中国地名信息，一键直达

你是否曾经需要查询某个地名的行政区划信息？是否在开发中需要获取标准地名、地理坐标等数据？今天介绍一款开源 CLI 工具，让你告别繁琐的网页操作，快速获取中国·国家地名信息库的全部数据。

## 什么是 area-cli？

area-cli 是一个基于民政部中国·国家地名信息库 API 开发的命令行工具，专为开发者、数据分析师、地理信息系统从业者设计。它能将复杂的 Web API 转化为简单高效的终端命令，让你用几秒钟完成以前需要反复点击网页才能完成的工作。

## 核心功能

**地名搜索** - 输入任意地名关键词，即可获取完整的地名列表，包括标准名称、类别、省市区划、拼音、地理坐标等信息。比如搜索"故宫"，瞬间返回全国所有包含"故宫"的地名。

**地名详情查询** - 通过地名 ID 获取精确到区县级别的详细信息，包括行政区划代码、地理坐标、数据来源等。

**同名区划统计** - 快速统计全国有多少个同名的行政区划，了解重名地区的分布情况。

**同名类别统计** - 按地名类别统计重名情况，比如"广场"有多少个、"医院"有多少家。

**同音区划统计** - 支持同音字查询，比如搜索"故宫"的同音字，能找到所有读音相似的地名。

## 为什么选择 area-cli？

**简单高效** - 一个命令完成查询，无需打开浏览器、无需手动翻页、无需复制粘贴。

**格式灵活** - 支持 JSON 和 Table 两种输出格式，JSON 方便程序处理，Table 方便人工阅读。

**跨平台支持** - 支持 macOS (Intel/Apple Silicon)、Linux、Windows 全平台，一条命令即可安装。

**本地缓存** - 内置 SQLite 缓存，24 小时内重复查询秒级响应，节省 API 调用、提升工作效率。

**开源透明** - 基于 MIT 协议开源，代码完全透明，没有任何隐私风险。

## 快速开始

### 安装方式

**Shell 安装（macOS / Linux）：**
```bash
curl -LsSf https://github.com/i-rs/area/releases/latest/download/area-installer.sh | sh
```

**npm 安装：**
```bash
npm install -g @i-rs/area
```

**从源码构建：**
```bash
git clone https://github.com/i-rs/area.git
cd area
cargo build --release
./target/release/area --help
```

### 使用示例

**搜索地名：**
```bash
area search 故宫
area search 故宫 -p 11          # 限定北京市
area search 故宫 -o table       # 表格输出
```

**查看详情：**
```bash
area detail <id>
```

**统计重名：**
```bash
area same-name-district 友谊
area same-name-type 广场
```

## 应用场景

**开发者的地理数据源** - 在应用程序中集成标准地名数据，无需自己维护数据库。

**数据分析师的好帮手** - 快速获取行政区划信息，用于数据清洗、统计分析。

**GIS 应用的便捷工具** - 查询地名坐标、获取标准地址，辅助地图可视化。

**地名研究者的效率神器** - 批量查询、统计分析，重名分布一目了然。

## 技术栈

area-cli 采用 Rust 语言开发，充分利用 Rust 的性能和安全性优势。核心技术栈包括： clap 实现命令行解析、reqwest 处理 HTTP 请求、serde 完成数据序列化、rusqlite 提供本地缓存、TikTok 运行时支持异步操作。

## 展望未来

area-cli 将持续迭代更新，计划中的功能包括：支持更多查询条件（如时间范围筛选）、支持导出更多格式（CSV、GeoJSON）、提供交互式查询模式、支持地名数据批量导入等。
